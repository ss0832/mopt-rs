mopt-rs
=======

mopt-rs is the successor implementation of MultiOptPy: geometry optimization and reaction
path exploration in Rust, with a Python interface and the commands of MultiOptPy.

The same documents are installed with the Python package (``python -m mopt_rs.docs``).
