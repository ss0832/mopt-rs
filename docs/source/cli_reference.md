# Command-line reference

mopt-rs provides the ten commands of MultiOptPy with the same options (extracted from
MultiOptPy 1.21.2 by `tools/cli/extract_multioptpy_cli.py`; this page is generated by
`tools/cli/gen_cli.py`). Each command is also available as a subcommand:
`mopt-py optmain input.xyz ...` (Python) or `mopt optmain input.xyz ...` (Rust binary).

The *Implemented* column says whether an option works in this version. Options that
are not implemented yet are parsed and rejected with exit code 2 when they are given a
value other than their default; commands that are not implemented yet parse their
options and exit with code 2.

| Command | Feature | Implemented |
|---|---|---|
| `optmain` | geometry optimization | yes |
| `nebmain` | reaction path methods (NEB and others) | yes |
| `ieipmain` | iEIP and other two-structure methods | yes |
| `mdmain` | molecular dynamics | yes |
| `confsearch` | conformation search | yes |
| `relaxedscan` | relaxed scan | yes |
| `orientsearch` | orientation search | yes |
| `run_autots` | automated transition-state search (AutoTS) | yes |
| `run_mapper` | reaction network mapper | yes |
| `run_rcmc` | rate constant matrix contraction (RCMC) | yes |
| `freqmain` | vibrational analysis and thermochemistry | yes |
| `ircmain` | intrinsic reaction coordinate (IRC) | yes |
| `run_kinetics` | kinetics of reaction networks (rate constants, populations; RCMC among the solvers) | yes |
| `run_automecp` | automated search for minimum-energy crossing points (MECP, MECI) | yes |
| `etmain` | electron-transfer rate constants (EDEEL diabatic states, SAES, Marcus with Scher-Holstein tunnelling, Zhu-Nakamura) | yes |
